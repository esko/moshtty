## 2024-05-18 - Avoid querySelector on Hot Keydown Paths
**Learning:** In a terminal web frontend, `document.addEventListener('keydown', ...)` intercepts every keystroke, making it a critical hot path. Using `document.querySelector` (like `document.querySelector("dialog[open]")`) forces the browser to parse the CSS selector and traverse the DOM on every single keypress, which introduces rendering latency and can delay terminal inputs.
**Action:** Replace `querySelector` on high-frequency event handlers with a cached, live `HTMLCollection` generated once at the module level using `document.getElementsByTagName("dialog")`. Iterating over this live collection with a simple length check and property access is an O(1) operation and significantly faster, preventing input latency.
