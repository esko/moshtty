## 2024-05-22 - Terminal Keystroke Latency on Document Keydown Handlers
**Learning:** In a terminal application, `document.addEventListener("keydown", ...)` is a massive hot path that intercepts every single terminal keystroke. Running expensive queries like `document.querySelector("dialog[open]")` or evaluating deep DOM traversals like `element.closest()` on this path introduces measurable, unnecessary latency to character rendering.
**Action:** Always verify what operations happen on hot paths like global keydown. Cache DOM elements instead of querying them, replace DOM query methods like `querySelector` with property checks on cached elements (`element.open`), and structure boolean logic to evaluate cheap, common-case checks (like `terminalRoot.contains(target)`) before expensive, rare ones (like `target.closest(...)`).
